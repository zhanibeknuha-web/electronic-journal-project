# Electronic Journal

## 1. Project Description

“Electronic Journal” is an information system designed to automate the tracking of academic activity.

The system will allow teachers to work with grades and attendance, and students to view their academic information.

## 2. Project Objective

The objective of the project is to create a convenient information system for storing and processing academic information and to reduce the number of manual operations.

## 3. Main Functions

* user registration and authorization;
* access rights management;
* management of student information;
* adding and viewing grades;
* attendance tracking;
* viewing academic information;
* administrative management;
* data storage in the database.

## 4. Project participants

* project manager;
* developers;
* administrator;
* teachers;
* students.

## 5. Delivery model

A hybrid delivery model (Hybrid) has been selected for the project.

The general stages of the project are planned in advance, while individual functions are developed in iterations.
